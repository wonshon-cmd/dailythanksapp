# daily bible — 두 번째 앱

daily thanks와 **같은 코드, 같은 데이터**로 만든 성경 앱이에요. `window.DT_APP = "bible"`이면 성경 모드로 열려요.

## 화면
- **읽기**: 마지막으로 읽은 곳(이어 읽기) · 통독 계기판 · 오늘의 본문(생명의 삶 / Our Daily Bread) · 성경 읽기 동행
- **설교 노트**: 녹음 / 녹음 파일 / 받아 적은 글 → AI가 한 장으로 정리(핵심 메시지 · 말씀 요점 · 삶의 적용 · 기도 제목 · 나눔 질문 · 본문) + 전체 받아쓰기
- **나**: 통독 계기판 · 연속 읽은 날 · 묵상 노트(성경 순서) · 저장한 구절 · 구독 · daily thanks 열기

## 새 설교 노트 순서
1. **본문** (녹음하려면 꼭 골라야 해요 — AI가 그 구절을 참고해 알아듣고 정리)
2. 설교 제목
3. **목사님 · 교회**: 처음 한 번 적으면 목록으로 기억해요. 요일·시간대별로 가장 자주 쓴 곳이 먼저 선택돼요(주일 11시 → 그 교회, 수요일 저녁 → 그 예배). "＋ 새로 입력"으로 바꿀 수 있어요.
4. **날짜**: 오늘로 자동, 바꿀 수 있어요.
5. 녹음 · 실시간 · 오디오 파일 → 설교 주제/이름 힌트 → 녹음 버튼
6. 핵심 메시지 · 내 노트

## 노트 보기: 요약 · 받아쓰기 · 본문
- **요약**: 한 장 정리 + 녹음 다시 듣기 + 내가 쓴 노트
- **받아쓰기**: 전체 글
- **본문**: 고른 본문 전체 + "설교에 나온 구절" 대조
  - AI가 구절마다 `match`(원문과 같음) / `paraphrase`(풀어서 말함) / `unsure`(확인 필요)를 표시해요(서버 요약 형식 `verse_checks`).
  - 앱이 성경 원문을 직접 불러와 한 번 더 비교해요. AI가 "같다"고 했어도 글자가 많이 다르면 "확인해 주세요"로 바꿔요.
  - 확인이 필요한 구절은 "맞아요" / "다른 구절이에요"(맞는 구절 입력)로 고쳐요. 요약 위에 "AI가 확신하지 못한 구절 n개" 알림이 떠요.
- 받아쓰기 엔진에도 고른 본문의 글과 낱말을 힌트로 넘겨요.

## 함께 읽기 계획 + 초대
- 읽기 탭 → "읽기 계획 만들기": 어디서부터 어디까지, 기간에 맞춰 / 하루 몇 장씩
- 만들면 바로 초대 시트: `dailyjourney.org/daily-bible/#plan?f=…&t=…&d=…&s=…` — 받은 사람은 같은 시작일·같은 분량으로 바로 함께해요(가입 없이).

## 데이터 연동
- 웹: `dailyjourney.org/app/`(daily thanks)와 `dailyjourney.org/daily-bible/`은 같은 사이트라 기기 안 기록을 그대로 같이 써요. 읽은 장·절, 묵상 노트, 저장한 구절이 서로 보여요.
- 휴대폰 앱 두 개: 로그인한 계정의 서버 기록(기기에서 잠근 상태로 저장)을 둘 다 읽어요. 실제 로그인을 붙이면 연결돼요.

## 설교 노트 요금 (구글 드라이브처럼 공간 기준)
화면 어디에도 "몇 개 남음" 같은 숫자는 보이지 않아요. 넉넉하게 쓰다가 공간이 차면 그때 "녹음 지우기 / 공간 늘리기"를 보여 줘요(설정에는 80% 넘으면 "거의 찼어요"만).

| | 무료 | 월간 | 연간 |
|---|---|---|---|
| 가격 | 0 | ₩4,900 / $3.99 | ₩39,000 / $29.99 (2개월 무료) |
| 공간 | 1GB (설교 녹음 약 50시간) | 100GB | 100GB |
| 자동 요약 | 공간 안에서 무제한 | 매달 60편까지 | 매달 60편까지 |

- 손으로 쓴 노트는 공간을 거의 안 써요. 녹음 1시간 ≈ 21MB(48kbps).
- 원가 주의: 무료 1GB를 다 쓰는 사람은 받아쓰기·요약 비용이 약 $15~20 들어요(1시간 ≈ $0.35). 부담되면 `FREE_STORAGE_MB`를 줄이면 돼요(예: 500 → 약 24시간).
- 서버 설정: `FREE_STORAGE_MB`(기본 1024), `PAID_STORAGE_GB`(기본 100), `SERMON_FAIR_USE`(기본 60/월)

## 서버 (fullstack/)
- `GET /api/sermons/quota` → `{ plan, used, limit, unit: 'bytes', notes, monthUsed, monthLimit }`
- `POST /api/sermons/text|audio`, 녹음 `finish` → 공간이 모자라면 `402 storage_full`(그 녹음은 남기지 않아요), 구독 중 월 60편을 넘으면 `429 fair_use`
- `DELETE /api/sermons/:id` → 지우면 그만큼 공간이 생겨요
- `POST /api/billing/activate` → **지금은 테스트용**(`BILLING_DEV=1`)이에요. 출시 전에 영수증 확인으로 바꿔야 해요:
  - iOS: StoreKit 2 구매 → App Store Server API로 서버에서 확인
  - Android: Google Play Billing → Play Developer API로 확인
  - 간단히 하려면 RevenueCat 같은 서비스로 두 스토어를 한 번에
- 요약: `server/sermons/summarize.js` (Claude Opus 5.5, 정해진 형식으로 출력, 거절되면 자동 대체 모델)
- 받아쓰기: `server/sermons/stt.js` (OpenAI Whisper / 네이버 CLOVA / 리턴제로 중 선택)
- `/daily-bible/` 주소로 성경 모드 페이지를 바로 내보내요.

## 녹음 · 받아쓰기 · 요약 (현재 상태)
- **새 설교 노트 화면** (Tiro처럼): 위에 **녹음 · 실시간 · 오디오 파일** 탭 → "교회, 설교자, 본문, 주제" 칸(적으면 받아쓰기가 더 정확해져요 — 받아쓰기 엔진의 단어 힌트와 요약에 함께 넘겨요) → 큰 **녹음** 버튼.
  - 실시간: 말하는 대로 바로 글자로 보여 줘요(브라우저 음성 인식, 한/영/스). 저장하면 녹음으로 한 번 더 정확하게 받아 적고, 서버가 없으면 실시간 글로 바로 요약해요. 휴대폰 앱 안에서는 브라우저 음성 인식이 없어 이 탭이 숨겨져요(네이티브 실시간 인식은 다음 단계).
  - 오디오 파일: m4a · mp3 · wav · mp4 파일을 골라 올려요.
- **녹음 버튼**: 새 설교 노트 맨 위에 "설교 녹음 시작". 녹음하면서 본문·핵심 메시지·노트를 같이 적을 수 있어요. 창을 닫아도 녹음은 계속되고, 설교 노트 화면에 "녹음 중 · 열기" 막대가 떠요.
- **휴대폰 전용 녹음기** (`SermonRecorder` 플러그인)
  - iOS (`ios/App/App/SceneDelegate.swift`): AVAudioRecorder, 백그라운드 오디오. 화면이 꺼져도, 다른 앱 소리가 나도 계속 녹음(`mixWithOthers`). 전화가 울리기만 하면 계속, 받으면 iOS가 마이크를 가져가서 잠시 멈추고 통화가 끝나면 자동으로 이어 녹음. 통화가 길어 앱이 잠들면 90초 뒤 "앱을 열면 이어서 녹음해요" 알림.
  - 안드로이드 (`SermonRecordService.java` + `SermonRecorderPlugin.java`): 마이크 포그라운드 서비스 + 알림 + 부분 wake lock. 울리는 중엔 계속, 통화 중(`MODE_IN_CALL`)에만 멈췄다가 끊으면 이어서.
  - 둘 다 AAC 모노 22kHz / 48kbps (1시간 ≈ 21MB).
- **웹**: MediaRecorder + 화면 켜 두기(Wake Lock). 교회 공간에 맞게 에코 제거·잡음 제거는 끄고(멀리 있는 목소리를 깎아 먹어요) 자동 음량만 켜요.
- **올리기**: 녹음이 끝나면 기기 안에 잠가서 보관한 뒤 4MB 조각으로 올려요(조각마다 재시도). 인터넷이 없으면 "다시 올리기" 버튼이 남아요.
- **설교에 맞춘 받아쓰기** (`server/sermons/stt.js`, `STT_PROVIDER=auto`)
  - 한국어 → 네이버 CLOVA Speech(키워드 부스팅) → 없으면 리턴제로 → 없으면 OpenAI
  - 영어 · 스페인어 → OpenAI `gpt-4o-transcribe` (`OPENAI_STT_MODEL`로 바꿀 수 있어요)
  - 먼저 ffmpeg로 소리를 다듬어요: 모노 16kHz, 저음 웅웅거림·고음 잡음 컷, 멀어졌다 가까워지는 목소리 음량 맞추기
  - 긴 설교는 10분씩 잘라 보내고, 앞 조각 끝부분을 다음 조각에 문맥으로 넘겨요
  - 언어별 성경 책 이름·인명·지명·교회 용어를 철자 힌트로 넘겨요(한/영/스)
  - 조용할 때 엔진이 지어내는 같은 문장 반복("감사합니다"×20)은 지워요
  - 필요한 설정: `CLOVA_SPEECH_INVOKE_URL`, `CLOVA_SPEECH_SECRET` (한국어), `OPENAI_API_KEY` (영어·스페인어), `FFMPEG_PATH`(기본 `ffmpeg`)
- **말로 한 구절 → 장절**: "요한복음 삼 장 십육 절" → "요한복음 3:16"
- **묵상 노트로**: 설교 노트에서 "묵상 노트로 남기기"

## 앱 열 때 먼저 보기 · 보기 설정 (daily thanks)
- 두 번째 날부터 앱을 열면: 순원 기도제목(한 장에 하나) → 오늘 읽을 말씀(한 절에 한 장) → 다 읽었어요 카드 → 평소 피드.
- 각 카드 위에 아주 작게 "어디서 왔는지"(예: 시편 함께 읽기 · 3일째 ?) — 누르면 "이게 뭐예요?" 설명과 보기 설정/24시간 끄기.
- 마지막 카드 아래 작은 링크: "이 화면 끄기 · 24시간 끄기".
- 설정 › 보기 설정: 먼저 볼 것(기도제목/말씀/챌린지), 기도제목 몇 개까지, 잠시 쉬기(24시간·일주일·끄기), 피드에 보일 것(감사/기도제목/묵상), 모르는 사람 글도 보기(기본 꺼짐 — 내 글과 연결된 사람 글만).
- 읽기가 밀리면: "n일 밀렸어요. 괜찮아요. 남은 d일에 나눠서 하루 x장씩 읽을까요?" → 끝나는 날은 그대로, 남은 분량을 고르게 다시 나눠요.

## 묵상 링크
- 내 묵상 → 링크 보내기 → `dailyjourney.org/app/#m=…` (내용은 # 뒤에만 담겨 서버로 가지 않아요). 받은 사람은 앱에서 본문과 묵상을 보고 "나도 묵상 쓰기".

## 소그룹 리더 도구 (설정 › 기능 › 소그룹 리더 도구 — 기본 꺼짐)
- 순모임: 본문 선택 → "순원들과 본문 함께 보기"(순원 화면에 '지금 순모임 중' 배너, 한 절씩 스크롤) → 출석 체크 → 녹음 → 저장 → 받아 적고 **순원별 나눔·기도제목**으로 정리(서버 `kind=meeting`, `summarizeMeeting`).
- 순원 리포트: 출석 점, 순모임에서 나눈 것, 기도제목, 순장 메모(순장·목사님만).
- 교회 대시보드: 다락방(분류)별 묶음, 출석률·이번 달 순모임 수, 이름 바꾸기, 멤버 옮기기, 리더 세우기.
- 목사님 보기 링크: 그 시점 대시보드를 # 뒤에 담은 링크(`/app/#pastor=…`). 정식 버전에서는 서버 로그인(목사님 권한)으로 바꿔야 해요 — 지금은 링크를 가진 사람은 볼 수 있어요.
