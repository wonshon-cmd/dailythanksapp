# Daily Thanks — 방향과 로드맵 (기억할 것)

> 2026-11-16 결정 사항입니다. 기능을 추가하거나 바꾸기 전에 먼저 읽으세요.

## 1. 핵심 원칙

- **기본 앱은 "감사"만.** 모든 사람이 최대한 간단하게, 자주, 많이 쓰게 하는 것이 목표입니다.
- 처음 여는 사람에게 보이는 것은 감사 피드, 감사 쓰기, 나의 감사뿐입니다. 다른 기능은 기본 화면에 나오지 않습니다.
- 새 기능이 감사 쓰기를 한 단계라도 더 어렵게 만들면 넣지 않습니다.

## 2. 나중에 추가할 기능 — 설정에서 켜서 쓰는 방식

다음 기능은 기본으로 **꺼 둡니다.** 필요한 사람만 **설정 › 기능**에서 켜면 해당 화면이나 메뉴가 나타납니다.

| 기능 | 내용 | 메모 |
|---|---|---|
| **AI 설교 요약** | 설교 녹음 → 음성을 글로 → 설교 노트(본문·핵심 메시지·요점·적용·기도제목·나눔 질문) | 서버 쪽은 `fullstack/`에 이미 있음(기능 플래그 꺼짐). 공유는 교회 동의가 필요 |
| **소그룹 나눔** | 소그룹 안에서만 보이는 나눔과 대화 | 지금의 소그룹 피드를 확장. 소그룹에서 잘 쓰일 수 있게 설계 |
| **기도제목 나눔** | 기도제목을 올리면 소그룹이나 친구들이 **「기도했어요」**를 누를 수 있음 | 누가 기도했는지 작성자에게 조용히 보여줌. 숫자 경쟁이 아니라 "함께 기도받고 있다"는 느낌으로 |

**설정 화면 구조 (예정)**

```
설정
├─ 언어 · 글자 크기 · 알림 시간 …
└─ 기능 (켜서 쓰기)
   ├─ 소그룹 나눔        [ ]
   ├─ 기도제목 나눔      [ ]
   └─ AI 설교 요약       [ ]
```

- 켜면 하단 메뉴나 감사 쓰기의 종류 선택에 해당 기능이 추가됩니다.
- 끄면 다시 감사만 남는 단순한 화면으로 돌아갑니다.
- 소그룹 리더가 그룹에 이 기능들을 추천하거나 켜 두는 방식도 고려합니다.
