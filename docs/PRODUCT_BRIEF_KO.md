# Daily Thanks — 제품·디자인 명세

## 1. 제품 개념

매일 30초~1분, 마음에 남은 작은 감사 한 줄을 기록하고 친구·가족·교회 소그룹과 나누는 공간. Scroll the Bible처럼 수직 전체 화면 피드를 한 포스트씩 넘기는 경험을 기본으로 한다. 공개 피드와 나의 소그룹은 구분한다. 종교적 사용자가 선택하는 **미리 감사** 기도도 핵심 기능.

**예시 문장:** “하나님, 이번 한 주도 직장에서 기쁨으로 하루하루를 보내게 하심에 감사합니다.”

## 2. 디자인 원칙

- 기본 배경 `#FCFCFA`, 카드 `#F6F6F4`, 본문 `#303438`, 보조글자 `#686E73`, 선 `#E5E6E3`, 주 버튼 `#444C53`
- 무채색에 가까운 Soft White. 강한 녹색/노랑/베이지 느낌을 피하고 종이처럼 부드러운 백색.
- 본문은 화면 중앙에 큰 글자로 표현. 여백이 넉넉하고 장식은 최소한.
- 하단 5개 주요 접근: 감사 피드 / 함께 7일 / 중앙 글쓰기 / 내 감사 / 위젯.
- 밝은 바탕 위 충분한 대비와 큰 터치 영역, 작은 디바이스에서도 사용 가능.

## 3. 주요 기능

1. **전체 화면 피드** — 한 장에 감사 한 개, 위로 스와이프/스크롤하여 다음 글. 내 소그룹/모두의 감사 탭.
2. **좋아요와 공유** — 다른 사람의 감사 좋아요, 원저자 표시, 링크/텍스트/카드 공유. 실제 구현에서는 게시물 공개 범위 및 동의 확인.
3. **소그룹/친구** — 그룹 만들기/초대, 그룹별 피드, 개인 및 소그룹별 공유 범위.
4. **7일 챌린지** — 소그룹/2인 참여, 7개 동그라미로 진행 표시, 1일 1회 기록, 중간에 쉬어도 재시작 강요하지 않음, 일주일 감사 앨범.
5. **오늘의 감사** — 오늘 실제로 있었던 작은 은혜를 돌아보며 기록.
6. **미리 감사** — 다가올 하루/한 주를 하나님께 맡기는 감사의 기도를 이미 이루어진 것처럼 표현하는 기록. 작성 후 같은 항목에 ‘돌아보며 감사’를 덧붙임.
7. **홈 위젯** — 오늘의 질문 + 즉시 작성 버튼, 소그룹 7일 진행상태. 실제 홈 위젯은 모바일 네이티브 코드가 필요.
8. **알림** — 사용자 선택 시간에 하루 최대 1회, 이미 작성한 날은 생략. 알림에 개인 기도나 그룹명 노출 최소화. 그룹 소식은 선택 후 모아서 전달.
9. **내 감사 아카이브** — 오늘/미리 감사 필터, 나중에는 월간/연간 감사 모음 영상 또는 스크롤 앨범.

## 4. 콘텐츠와 질문 예시

- 오늘 나를 웃게 한 순간은?
- 이번 주에 감사하고 싶은 사람은?
- 사소하지만 당연하지 않았던 일은?
- 하나님, 이번 한 주도 직장에서 기쁨으로 하루하루를 보내게 하심에 감사합니다.
- 하나님, 이번 주 만나는 사람들을 사랑과 인내로 대하게 하심에 감사합니다.

## 5. 운영·제품 전략

- 첫 방문에서 바로 한 줄 쓸 수 있도록 시작 단계 최소화.
- 첫 감사를 쓴 직후에만 알림 권한을 맥락 있게 물어보기.
- 지속 사용: 정해진 시간의 알림 → 위젯의 질문 → 30초 기록 → 공감 반응 → 주말 일주일 감사 돌아보기.
- 스트릭 압박과 공개 순위는 기본값으로 넣지 않음.
- 그룹의 공개 범위를 분명히 표시하고 보안·유해 콘텐츠 대응 정책을 갖출 것.

## 6. 실서비스 전환 시 권장 데이터 구조

`users`, `groups`, `group_members`, `posts(id,user_id,scope,group_id,kind,text,created_at)`, `likes`, `post_reflections`, `challenges`, `challenge_members`, `challenge_checkins`, `notification_preferences`, `reports`, `blocks`.

인증, 서버 측 접근 통제, 게시물 권한, 데이터 보관/삭제, 미성년자 개인정보, 콘텐츠 신고/차단을 구현할 것. 다른 사람의 비공개 감사가 공유되거나 검색되지 않게 할 것.

## 7. 이 번들의 한계

이전 채팅에서 렌더링된 원본 프로토타입 소스가 이 작업 환경에 존재하지 않아, 대화에서 합의된 최신 디자인과 기능을 근거로 **이동 가능한 버전을 재구현**했다. 완전히 동일한 원본 파일은 아니지만 기능과 디자인 방향을 이어갈 수 있는 독립적인 시작점이다.
