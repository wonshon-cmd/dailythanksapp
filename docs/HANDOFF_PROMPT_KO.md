# 다른 AI/개발자에게 전달할 프롬프트

`DailyThanks_Starter.zip`을 프로젝트로 열고, 현재 HTML/CSS/JavaScript를 기본 디자인으로 사용해 Daily Thanks를 계속 개발해주세요. **현재의 밝은 Soft White 컬러(#FCFCFA), 넉넉한 여백, 큰 타이포그래피, 전체 화면 수직 감사 피드, 소그룹/전체 공개 분리, 오늘의 감사와 미리 감사 구분은 유지**해주세요.

우선순위:
1. 앱을 실행하고 기존 화면과 기능을 파악하며 모바일에서 테스트하기.
2. Firebase 또는 Supabase 등 실제 인증/데이터베이스 구조 설계하기. 비공개 및 소그룹 글 권한은 서버 측에서 적용하기.
3. 구글/애플 로그인, 소그룹 초대 및 가입, 개인·그룹·공개 게시, 좋아요 및 공유 링크 구현하기.
4. ‘함께 7일’ 챌린지를 날짜와 **참여자별** 체크인으로 정확하게 계산하고 주간 감사 앨범 만들기.
5. 미리 감사에 실제 경험을 연결하는 회고 기능과 정기 알림 구현하기.
6. iOS/Android 홈 위젯과 네이티브 앱, 카카오톡/인스타그램 공유 연동 검토하기.
7. 신고/차단/삭제/보안/개인정보 보호와 접근성을 출시 전에 점검하기.

중요:
- 이 번들은 실서비스가 아니라 오프라인 데모이다. `localStorage` 기반 동작과 화면에 보이는 알림·위젯은 실제 원격 동기화/푸시 기능이 아니다.
- 현재 디자인을 갑자기 리브랜딩하지 말고, 기존 UI를 발전시킨다.
- `PRODUCT_BRIEF_KO.md`의 상세 요구사항을 참고한다.
- ‘하나님, 이번 한 주도 직장에서 기쁨으로 하루하루를 보내게 하심에 감사합니다.’ 는 미리 감사 예시로 유지한다.
