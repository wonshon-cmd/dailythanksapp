# Daily Journey (성경 앱) — 스토어 제출 전 점검 자료

> 이 파일과 같은 묶음(zip)에 앱 소스(`app.js`, `styles.css`, `index.html`), 서버 규칙(`supabase/schema.sql`),
> 휴대폰 앱 설정(`mobile/…`), 스토어 문서(`store/…`), 자동 점검 결과(`button-check.txt`)가 들어 있어요.
> ChatGPT에 zip을 올리고 맨 아래 **"ChatGPT에게 붙여 넣을 질문"** 을 그대로 붙여 넣으면 돼요.

## 1. 앱 한 줄 소개

- 성경을 매일 읽고, 공동체와 기도제목·감사·묵상을 나누는 앱이에요.
- 한국어·영어·스페인어. 무료, 앱 안 구매 없음, 광고 없음.
- 스토어 이름 **Daily Journey**. 앱 ID `org.dailyjourney.app` (iOS·Android 같음).
- 웹 버전(github.io)은 같은 코드를 "daily bible"이라는 이름으로 보여 줘요.

## 2. 구조

| 부분 | 내용 |
|---|---|
| 앱 화면 | `app.js` + `styles.css` + `index.html` (프레임워크 없는 순수 JavaScript). `window.DT_APP="bible"`, `window.DT_BRAND="journey"`로 Daily Journey가 돼요. |
| 휴대폰 앱 | Capacitor 8 (`mobile/`). 웹 화면을 그대로 감싸요. 성경 본문은 앱 안에 들어 있어서 오프라인으로도 읽혀요. |
| 서버 | Supabase (로그인 + Postgres). 앱에는 **Project URL과 공개(publishable) 키만** 있어요. 비밀 키는 앱 어디에도 없어요. |
| 권한 규칙 | 누가 무엇을 볼 수 있는지는 데이터베이스의 Row Level Security(`supabase/schema.sql`)가 정해요. |
| 개인정보 | "나만 보기" 글은 기기 밖으로 나가지 않아요(기기에서 잠가서 보관). 공동체 글은 그 공동체 멤버만, "모두" 글은 로그인한 사람 모두가 볼 수 있어요. |

## 3. 화면과 버튼 — 눌렀을 때 일어나야 하는 일

### 처음 열었을 때
| 버튼/화면 | 기대 동작 |
|---|---|
| 둘러보기(투어) | 피드가 저절로 위로 밀리는 데모(말씀 → 공동체 기도제목 → 감사). [건너뛰기]·[다음] |
| 기능 3개 | 읽기 · 설교 노트 · 공동체 소개 → [시작하기] |
| 이름 묻기 | 이름 입력 → [다음] |
| 가입 | 메일(+ Supabase에서 켠 경우만 문자/Google/Microsoft). 휴대폰 앱에서는 메일·문자만. [나중에] 가능 |
| 메일 로그인 | 이름+메일 → 메일 발송 → 메일 속 숫자 코드 입력(앱) 또는 링크(웹) → 로그인. 한 번 로그인하면 로그아웃 전까지 유지 |
| 초대 링크로 들어옴 | 투어 대신 "공동체에 참여할까요?" → [참여하기] → (로그인 안 했으면) 로그인 → 자동 참여. 승인제면 "승인 대기" |

### 피드 (전체 화면 스크롤)
| 버튼 | 기대 동작 |
|---|---|
| 위로 밀기 | 다음 카드 (말씀·기도제목·감사·묵상) |
| ♡ / 기도했어요 | 좋아요 / 기도했어요 토글. 로그인 상태면 서버에 반응 저장 |
| 북마크 | 저장 토글 |
| ⋯ | 숨기기 · 차단 · 신고 메뉴 |
| 공유 | 공개 글만. 남의 공동체·비공개 글은 공유·복사·캡처 막음 |
| 닫기(⤡) | 항상 「읽기」 화면으로 |
| + | 감사 · 기도제목 · 묵상 · 감사 전하기 쓰기 메뉴 |
| 이 화면 끄기 | 무엇을(기도제목·오늘 읽을 말씀·챌린지·전부) 얼마나(24시간·일주일·다시 켤 때까지) 끌지 고르기 |
| "새 글 N" | 숫자 표시만(누르면 아무 데도 안 감 — 의도된 동작) |
| 언어 🌐 | 처음 5번 방문 동안 모든 화면 오른쪽 위에 보임 |

### 쓰기
| 항목 | 기대 동작 |
|---|---|
| 감사 | 기본 공개 범위 **모두** |
| 기도제목 · 묵상 | 기본 공개 범위 **내 공동체**. 마지막으로 고른 공동체를 종류별로 기억 |
| 묵상 | 오늘 본문이 한 절씩 카드로 보임. 좌우로 밀거나 ‹ › 로 넘김. 느낀 점·기도는 손으로 입력(녹음 없음) |

| 저장 | 공동체/모두 글은 로그인 상태면 Supabase에 올라감. 나만 보기는 기기에만 |

## 4. 서버(Supabase) 규칙 요약 — `supabase/schema.sql`

- 테이블: profiles, groups, group_members, posts, reactions, challenges, challenge_members, meetings, member_notes, churches, church_roles, **reports**.
- 로그인하지 않은 사람(anon)은 어떤 테이블도 못 읽음.
- posts 읽기: 내가 쓴 글 · 모두 공개 글 · 내가 멤버인 공동체 글만.
- 공동체 가입은 `join_group(code)` 함수로만(초대 코드 필요). 승인제면 pending.
- 신고는 누구나 넣을 수 있고 읽기는 운영자만(대시보드).
- **계정 삭제** `delete_my_account()`: 로그인한 본인 계정을 지우면 프로필·글·반응·멤버십이 함께 지워짐.

## 5. 자동 점검 결과

- 모든 화면(피드·읽기·설교 노트·공동체·공동체 상세·나·설정·쓰기 메뉴)에서 보이는 버튼을 **하나씩 새 화면에서 눌러 본 결과**: `button-check.txt`
- 결과 읽는 법: `ok` = 눌렀을 때 화면이 바뀜, `NO VISIBLE CHANGE` = 같은 탭을 다시 누른 경우처럼 바뀔 것이 없거나(정상), 점검 도구가 못 보는 변화(예: 글자 크기, 성경 고르기 창). `ERROR` = 오류.
- 로그인 상태 흐름(가짜 서버로 시험): 메일 코드 로그인 → 공동체 연결 → 기도제목 올리기 → 남의 기도제목 받기 → 기도했어요 → 신고 → 계정 삭제까지 서버 요청이 맞게 나감.

## 6. 남은 일 (사람이 직접)

1. **Supabase SQL Editor에서 `schema.sql` 다시 실행** (신고 테이블, 계정 삭제 함수, 순장 보기 설정 칸이 새로 생김).
2. **메일 템플릿에 숫자 코드 넣기**: Authentication › Emails › Magic Link·Confirm signup 템플릿에 `{{ .Token }}` 추가. 휴대폰 앱은 이 코드로 로그인해요(메일 링크는 브라우저로 열리기 때문).
3. **전용 메일 서비스(SMTP) 연결**: 기본 메일은 시간당 몇 통뿐.
4. **dailyjourney.org의 /privacy, /terms, /support, /delete-account 페이지가 실제로 열리는지** 확인(앱 안 링크가 거기로 가요).
5. **심사용 계정**: 숫자 코드로 들어갈 수 있는 테스트 계정, 공동체 하나와 다른 사람 글 몇 개.
6. Xcode 서명 · App ID · App Group, Play 앱 서명 키 — `store/SUBMISSION_CHECKLIST_KO.md`.
7. 문자 로그인을 쓰려면 Twilio 등 문자 서비스를 Supabase에 연결(안 하면 문자 버튼은 안 보여요).

## 7. 판단이 필요한 것 / 알려진 한계

- **"생명의 삶"**: 오늘의 본문 출처로 다른 출판사 큐티 책 이름과 일정이 보여요. 써도 되는지 확인이 필요해요.
- **공동체 글의 암호화**: 공동체 글은 서버에 평문으로 저장돼요(멤버만 읽을 수 있게 권한으로 막음). "운영자도 못 보게" 하려면 공동체 열쇠로 잠가야 하는데, 그러면 코드로 들어온 사람은 열쇠가 없어 글을 못 읽어요.
- **다른 기기에서 쓴 내 글**: 다른 기기에서 올린 내 글은 이 기기에 아직 안 보여요.
- **알림**: 매일 알림은 기기 안 알림(Local Notifications). 서버 푸시는 없음.
- **샘플 내용**: 로그인 전에는 샘플 글에 "샘플" 표시가 붙고, 로그인하면 샘플이 사라져요.
