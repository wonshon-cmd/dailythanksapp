# Daily Thanks — UI/UX 가이드

원칙은 하나입니다: **쓰기 편하고, 간단하고, 조용하게.**

## 1. 흐름

1. **첫 화면:** 흰 바탕에 `daily thanks`. 손을 대면 바로 사라집니다.
2. **전체 화면 피드:** 다른 사람들의 감사가 한 장에 하나씩 나옵니다.
   - 연한 로고, 연한 작성자 줄, 오른쪽에 ♡ 숫자 · 공유 · 닫기가 있습니다.
   - 처음 방문했을 때만 "아래로 넘겨 보기" 안내가 나옵니다.
3. **감사 3개 뒤:** 오늘 나의 감사를 쓰는 카드가 나옵니다. 기본은 모두에게 공개이고, 나만 보기로 바꿀 수 있습니다.
4. **그다음:** 로그인 카드(Apple · Google · 휴대폰)가 나옵니다. 한 번 로그인하면 계속 유지됩니다.
5. **닫기를 누르면** 일반 화면입니다. 상단 로고와 `감사 쓰기`, 하단 4개 메뉴(오늘 · 소그룹 · 함께 7일 · 나의 감사)가 보입니다.

## 2. 화면 규칙

- **화면 하나에 제목 하나.** 26px Light, 설명은 한 줄(14px)입니다. 영어 대문자 소제목과 안내 문구는 쓰지 않습니다.
- **추가 동작은 제목 오른쪽 동그란 버튼 하나.** 소그룹 `+`, 함께 7일 `+`, 나의 감사 `⋯`(설정)입니다.
- **같은 동작은 한 곳에서만.** 감사 쓰기는 상단 `감사 쓰기` 버튼, 설정은 나의 감사의 `⋯`에서만 엽니다.
- **목록은 상자 대신 가는 구분선.** 행 전체를 누를 수 있고, 다음 단계가 있으면 오른쪽에 `›`를 둡니다.
- **선택은 드롭다운 대신 세그먼트·칩.**
  - 종류(오늘의 감사 / 미리 감사 / 감사 전하기)와 공개 범위(모두 / 소그룹 / 나만)는 세그먼트입니다.
  - 소그룹 고르기는 칩입니다.
- **글은 가장 큰 요소.** 입력창은 테두리 없이 밑줄만 두고 20px Light로 씁니다. 저장 버튼은 하나입니다.
- **나누는 쪽이 기본.** 공개 범위의 기본은 "모두"이고, "나만"으로 언제든 바꿀 수 있습니다. "모두"가 선택되어 있으면 공개 안내 한 줄이 보입니다. 감사 전하기 카드는 개인적인 글이라 나만 보기로 저장됩니다.
- **시안 안내는 한 곳에만.** 설정 맨 아래에 모았습니다.

## 3. 구성 요소

| 요소 | 규칙 |
|---|---|
| 아이콘 | 얇은 선 아이콘만 사용합니다 (stroke 1.3–1.5). 텍스트 기호(＋ ⋯ × ✓)는 쓰지 않습니다. |
| 기본 버튼 | 진한 회색 알약 모양, 높이 48, 한 화면에 하나 |
| 보조 버튼 | 흰 바탕 + 테두리 알약, 높이 44 |
| 텍스트 버튼 | "나중에 쓸게요"처럼 덜 중요한 선택 |
| 세그먼트 | 연회색 바탕 위 흰 알약이 선택된 상태 |
| 시트 | 위쪽 손잡이, 제목 19px, 오른쪽에 ✕ 아이콘 |
| 색 | 바탕 `#FCFCFA`, 글 `#303438`, 보조 `#686E73`, 연한 `#9BA0A3`, 선 `#E5E6E3`, 버튼 `#2F3337`, 삭제 `#B4585F` |
| 글꼴 | 로고 Newsreader(thanks는 이탤릭), 본문 Noto Sans KR Light. 영어도 같은 글꼴을 씁니다. |

## 4. 화면별 정리

- **소그룹:** 그룹 목록(이름 · 감사 n개 · ›)이 나오고, 누르면 그 그룹 피드로 갑니다.
- **함께 7일:** 챌린지 카드 하나에 이름, 7개 동그라미, `오늘의 감사 쓰기`가 있습니다. 카드 제목을 누르면 상세가 열립니다.
- **나의 감사:** `전체 / 오늘의 감사 / 미리 감사` 세그먼트와 글 목록이 있습니다.
  - 글을 누르면 공유 · 돌아보며 감사 쓰기(미리 감사만) · 삭제가 나옵니다.
- **감사 쓰기:** 종류 → 글 → 누구와 → 남기기. 미리 감사일 때만 예문 칩이 나옵니다.
- **공유:** 카드 미리보기 아래에 텍스트 복사 · 소그룹에 나누기 · 다른 앱으로 공유가 있습니다.
- **설정:** 언어, 계정, 알림 시간, 홈 위젯, 전체 화면, 데이터 복사, 초기화 순서입니다.
